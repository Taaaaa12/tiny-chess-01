A 4 KB Python chess engine: alpha-beta search with quiescence, a transposition table, killer-move and history move ordering, tapered piece-square evaluation with a bishop-pair bonus, and a fixed node budget — no clock, no randomness, fully deterministic. The readable source is `engine.py`; `main.py` is the same engine packed with `makefun compress` to fit the 4,096-byte cap.

## Run it

```sh
MAKEFUN_ENV_URL=$MAKEFUN_ENV_URL python3.13 main.py
```
